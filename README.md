# Weather App

Search a city and see current weather and a 7-day forecast.

## Features
- Two-step lookup: city name to coordinates, then weather
- Loading, error, and "city not found" states
- Press Enter to search
- Remembers the last city (localStorage)

## Setup
1. Get a free API key from openweathermap.org
2. Copy `config.example.js` to `config.js` and paste your key
3. Open with VS Code Live Server
